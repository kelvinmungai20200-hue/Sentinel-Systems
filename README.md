# Sentinel Systems - Website Scanner
**Cybersecurity Auditor with Automated M-Pesa Reporting**

Sentinel Systems is a dedicated platform designed to help small and medium-sized enterprises (SMEs) in Kenya secure their digital presence. It automates technical audits and provides professional security reports to protect businesses from cyber threats.

## Key Features
- **Comprehensive Audit:** Scans SSL certificates, security headers, and server stability in real-time.
- **Vulnerability Insights:** Provides detailed technical feedback on the security posture of any web application.
- **M-Pesa Integration:** Automated billing system powered by Safaricom Daraja API for seamless professional PDF report exports.
- **Modern UI/UX:** Features a responsive, Cyberpunk-themed dashboard built for high-performance monitoring.

## Technology Stack
- **Backend:** Python (Flask / FastAPI)
- **Frontend:** HTML5, CSS3, JavaScript
- **FinTech Integration:** Safaricom M-Pesa API (Daraja)
- **Security Logic:** Custom algorithms for SSL analysis and HTTP header auditing.

##  Business Vision
Sentinel was built to bridge the gap between high-cost cybersecurity services and local SMEs. Our mission is to provide enterprise-grade security tools at an affordable, local price point.

##  Installation & Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Environment Setup:**
   Create a `.env` file in the root directory and add your Safaricom Daraja credentials and Base URL.
4. **Run the Application:**
   ```bash
   python main.py
   ```
